## ⚡ How to Run Locally

### Option 1: Double Click
Simply double-click `index.html` in your file explorer to open it directly in Google Chrome, Microsoft Edge, Brave, or Safari.

### Option 2: Using VS Code Live Server
1. Open the `vision-web-tech` directory in VS Code.
2. Right-click `index.html` and click **"Open with Live Server"**.

### Option 3: Using Python HTTP Server (if Python is installed)
In PowerShell / Terminal:
```bash
cd "vision-web-tech"
python -m http.server 3000
```
Open `http://localhost:3000` in your browser.
